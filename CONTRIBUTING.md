# Как помочь

Нашли ошибку или хотите функцию - заведите issue с описанием, версией и (без секретов) выводом.

Перед pull request:

```
python3 -m venv venv
venv/bin/pip install -r requirements-tui.txt -r requirements-dev.txt
make check
```

Требования: ruff, mypy и bandit чистые, тесты проходят, покрытие не ниже 85%. Тесты не должны ходить во внешние
сети и открывать окна (`NO_OPEN_SCREENSHOT=1`). В коде и документации только символы с клавиатуры
(`->`, `-`, прямые кавычки); текст на русском допустим. Новый мессенджер делается по образцу
`monitor/messengers/telegram.py`.
