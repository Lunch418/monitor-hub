# Планы

## В работе

- `ProtectSystem=strict` с `ReadWritePaths` для каталога состояния: нужна проверка на настоящей службе (systemd-nspawn или ВМ).
- Режим только проверки без записи состояния (`check --no-send` уже не шлёт в чат, но состояние пишет).

## Дальше

- Выделить интерфейс `Collector` (папки, письма, потом статус служб и свободное место).
- Экспорт состояния в формате Prometheus (`/metrics`, только чтение, без секретов).
- Файл-метка живости демона для внешней проверки (`WatchdogSec`).
- Ещё мессенджеры (Matrix, Slack) по образцу `monitor/messengers/telegram.py`.

## Отложено осознанно

- Веб-панель: инструмент остаётся терминальным, для графиков есть Prometheus и Grafana.
- Плагины отдельными пакетами: сначала нужен стабильный интерфейс `Collector`.
- Публикация в PyPI и подпись релизов: решение владельца репозитория, не часть кода.
- `MemoryDenyWriteExecute`: ломает часть расширений Python, выигрыша для этого демона мало.

## Проверено тестами

- Обрыв шлюза при входе повторяется; обрыв после входа даёт понятную ошибку без секретов, следующая проверка проходит
  (`tests/test_gateway.py`). Повтор внутри одного запуска после входа сознательно отключён.
