# PAM-шлюз

monitor-hub умеет входить на машину двумя способами: напрямую по ssh (`via = "ssh"`) и через PAM jump-хост
(по умолчанию). Здесь описан второй.

## Как выглядит диалог

1. `ssh <pam_user>@<PAM_HOST>`, ввод пароля.
2. Шлюз показывает меню выбора, например `select one:` и список машин.
3. Программа вводит адрес или номер из `target_host` (или `target_sel`).
4. Шлюз открывает сеанс на машине; программа ждёт приглашение командной строки.
5. Все пути проверяются за этот один вход, затем сеанс закрывается.

Если у цели задан `pam_host` / `pam_port`, используется он, иначе общий `PAM_HOST` и `PAM_PORT` из `.env`.
Входы на один и тот же шлюз ограничены (`MAX_PARALLEL_LOGINS`, `GATEWAY_LOGIN_GAP`).

## Ограничение

Шаблоны ожидаемых строк (`select one:`, приглашение, запрос пароля) зашиты в `monitor/pam_session.py`.
Если у вашего шлюза диалог другой, правьте их там; программа в этом случае сообщает, на каком этапе
вход не удался ("на jump-хосте" или "на машине"). Если шлюза нет, используйте `via = "ssh"`.

## Устаревшие алгоритмы

Старые шлюзы часто требуют устаревшие kex и ключи хоста. Они задаются в `.env` и по умолчанию
не включаются, если поля пустые.
